# Customer Sales Analysis

## Project Overview

This project performs customer sales analysis using Python and data analysis libraries. The objective is to analyze customer purchasing behavior, identify sales trends, and gain insights from sales and customer churn datasets.

The project uses data manipulation, aggregation, pivot tables, and visualizations to understand business performance.

---

## Objectives

* Analyze total sales revenue
* Identify top customers
* Understand regional sales performance
* Analyze product sales trends
* Study customer churn behavior

---

## Datasets Used

1. **sales_data.csv**

   * Contains product sales information including date, product name, quantity, price, region, and total sales.

2. **customer_churn.csv**

   * Contains information about whether a customer has churned or not.

---

## Technologies Used

* Python

* Matplotlib

## Project Workflow

## How to Run the Project

1. Clone the repository

```
git clone https://github.com/your-username/customer-sales-analysis.git
```

2. Install required libraries

```
pip install -r requirements.txt
```

3. Open the notebook in **Google Colab** or **Jupyter Notebook**

4. Run all cells to generate analysis and visualizations.
